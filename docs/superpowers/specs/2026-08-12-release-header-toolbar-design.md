# Release Header Toolbar Design

**Date:** 2026-08-12

## Final layout

The Release page reuses the same page-header toolbar as Create: Target System, the target dropdown, and the complete Sync CR menu. Release does not render a separate Refresh button or Last synced label.

Changing Target System automatically reloads Release candidates. After a successful Sync CR operation launched from Release, candidates reload again. The Select Transport Request card retains only its step heading, guidance, search field, candidate table, and empty/loading states.
